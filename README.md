# Datathon 2026 - The Gridbreakers

Báo cáo và mã nguồn phân tích doanh thu thời trang Việt Nam (2012-2022).

## Cấu trúc dự án
- `notebooks/`: Chứa mã nguồn phân tích EDA và mô hình dự báo.
- `report.tex`/`report.pdf`: Báo cáo kỹ thuật chi tiết.
- `dataset/`: Thư mục chứa dữ liệu đầu vào (.csv).

## Hướng dẫn sử dụng
1. Cài đặt thư viện: `pip install -r requirements.txt`
2. Đặt dữ liệu vào thư mục `dataset/`.
3. Chạy các file trong `notebooks/` để xem kết quả.
